# Promptexa

Visual AI prompt discovery platform.

## Stack
- Next.js App Router
- TypeScript
- Supabase/PostgreSQL
- Vercel
- Android client using the same backend

## Product
- 50,000+ structured prompts
- Visual examples for image prompts
- Detailed video concepts without hosting video files
- Search, filters, categories, AI models, tags and collections
- Copy/save/share flows
- Free-tier-first infrastructure
- SEO-first public prompt pages
- Professional responsive web UI

## Principle
Discover → See → Understand → Copy → Create

Build an original product informed by broad benchmark research; do not copy third-party designs.
